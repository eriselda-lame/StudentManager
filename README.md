# StudentManager

A Java Swing desktop application for managing students.

## Features
- Add students
- Display students in a table
- Delete students
- Sort students alphabetically
- Save student data to a text file

## Technologies
- Java
- Java Swing
- Apache NetBeans
- Git and GitHub

## How to Run
1. Open the project in Apache NetBeans.
2. Run the `StudentUI` class.
